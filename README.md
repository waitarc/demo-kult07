# Культура 07 — демо-сайт

React + Vite. Фото четырёх мастеров и исходный прайс-лист добавлены в `public/` из материалов, предоставленных заказчиком.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
npm run preview
```

Сайт адаптивный, с плавной навигацией, reveal-анимациями, интерактивным фильтром прайса и раскрывающимися карточками мастеров. Кнопки записи ведут на телефон организации. Фото работ/интерьера из карточки Яндекс Карт подгружаются с CDN Яндекса.
